# Unemployment Analysis in India (CodeAlpha – Task 2)

## Project Overview
This project analyzes unemployment rate data in India using Python.
The aim is to study unemployment trends, understand the impact of Covid-19,
identify seasonal and regional patterns, and extract insights useful for
economic and social policy planning.

## Objectives
- Analyze unemployment rate data (percentage of unemployed people)
- Perform data cleaning and exploration using Python
- Visualize unemployment trends over time
- Investigate the impact of Covid-19 on unemployment rates
- Identify seasonal and regional patterns
- Present insights useful for policy making

## Dataset
File Name: Unemployment in India.csv

The dataset contains information such as:
- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Urban / Rural)

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Project Structure
CodeAlpha_Unemployment_Analysis/
- unemployment_analysis.py
- Unemployment in India.csv
- README.md

## Steps Performed
1. Loaded the dataset using Pandas.
2. Cleaned the data by removing extra spaces and handling missing values.
3. Converted date column to datetime format.
4. Performed exploratory data analysis using statistics.
5. Visualized unemployment trends over time.
6. Analyzed the impact of Covid-19 on unemployment.
7. Compared unemployment rates in urban and rural areas.
8. Identified seasonal trends using monthly analysis.

## Key Insights
- Unemployment increased significantly during the Covid-19 period.
- Urban areas were more affected compared to rural areas.
- Certain months show higher unemployment indicating seasonal patterns.
- Some regions consistently have higher unemployment rates.

## Policy Implications
- Employment schemes can be planned during high unemployment periods.
- Urban employment support is crucial during economic crises.
- Seasonal analysis helps in proactive job planning.
- Data-driven policies can reduce unemployment impact.

## How to Run
1. Place the dataset in the project folder.
2. Open terminal in the project directory.
3. Run the command:
   python unemployment_analysis.py

This project shows how unemployment data can be analyzed using Python to
